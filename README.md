# Pyhtää Water Cooperative website

Source for the Elementor rebuild of https://pyhtaanvok.fi (staging: pyhtaanvok.fi-c.seravo.com).

- `wp-content/themes/pyhtaa-child/` – Hello Elementor child theme. Pages, header and footer are built in Elementor / Ultimate Addons for Elementor; the theme only adds the design's animations (wave edges, blobs, drifting lines), scroll reveal, the menu drawer and the quick-link cycling.
- `wp-content/themes/pyhtaa-child/assets/svg/` – logo, icons and decorative SVGs that are imported into the Media Library.
